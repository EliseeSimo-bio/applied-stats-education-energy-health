# INF5103 — Devoir I : analyse statistique de quatre jeux de données

Travail réalisé dans le cadre du cours **INF5103 — Concepts statistiques pour la science des données** (UQO, automne 2026).

Auteur : Elisée Bertrand Lele Simo

## Contenu

| Fichier | Description |
|---|---|
| `LeleSimo_Devoir_I.ipynb` | Notebook Python : code, résultats et commentaires des quatre jeux |
| `plateforme_apprentissage.csv` | Jeu 1 — plateforme d'apprentissage |
| `consommation_batiment.csv` | Jeu 2 — consommation énergétique d'un bâtiment |
| `dossiers_patients.csv` | Jeu 3 — dossiers patients |
| `latence_service.csv` | Jeu 4 — latence d'un service |
| `rapport/LELESIMO_Devoir_I.pdf` | Rapport remis |

## Exécuter le notebook

```bash
pip install -r requirements.txt
jupyter notebook LeleSimo_Devoir_I.ipynb
```

Les fichiers CSV doivent rester dans le même dossier que le notebook. Exécuter ensuite *Kernel → Restart & Run All*. Les figures (`fig_*.png`) sont régénérées à l'exécution.

## Outils

Python 3, pandas, NumPy, Matplotlib, Jupyter.
